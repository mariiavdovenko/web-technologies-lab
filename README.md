лабораторних робіт.

Тема: Основи роботи з GitHub.

## Автор

Вдовенко Марія

## Індивідуальне завдання — варіант 3

Створити репозиторій для JavaScript-проєкту.

У проєкті реалізовано кнопку «Показати привітання».
Після натискання JavaScript виводить повідомлення:
«Привіт! JavaScript працює!».

Код JavaScript розміщено у файлі script.js.

## Запуск проєкту

Завантажте та розпакуйте ZIP-архів репозиторію.
Відкрийте index.html у браузері та натисніть
кнопку «Показати привітання».
Файли style.css і script.js мають бути поруч з index.html.
